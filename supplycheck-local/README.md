# SupplyCheck legal publication set

Public legal, privacy, purchase, refund, support, and disclaimer pages for **SupplyCheck 2.1.0 on Android** and **SupplyCheck 2.0.0 on iPhone/iOS**.

**Document version:** 22 August 2026

Authoritative routes:

- `/supplycheck-local/`
- `/supplycheck-local/privacy/`
- `/supplycheck-local/terms/`
- `/supplycheck-local/purchases/`
- `/supplycheck-local/refunds/`
- `/supplycheck-local/support/`
- `/supplycheck-local/disclaimer/`

SupplyCheck is the current local-first stock-control product. The commercial model is platform/version specific:

- Android 2.1.0: full inventory feature set with a permanent non-personalized bottom advertising banner unless an optional US$2.99/month Google Play ad-free subscription is active; localized Play checkout price controls.
- iPhone/iOS 2.0.0: existing one-time paid, no-ad version.

These pages do not describe the retired delivery-discrepancy prototype. Android advertising and billing network processing is separate from the local inventory ledger and is documented in the privacy and purchase pages.
