# SWF One — legal and support

**Publisher:** WorksBien Studios Inc., Ontario, Canada  
**Android package:** `com.worksbien.swfone`  
**Updated:** 19 November 2026

- [Privacy Policy](./privacy/)
- [Subscription Terms](./subscriptions/)
- [Open-source Licenses](./licenses/)
- [Support and Data Removal](./support/)

SWF One is an Android player for user-selected SWF files and web addresses. Basic file and web playback, pointer input and full screen are available without a subscription. The optional monthly or annual subscription unlocks the virtual gamepad, gaming keyboard, saved control layouts, recent-content resume and opt-in Android cloud backup of supported play-setup data. There is no free trial.

Compatibility varies by SWF title, ActionScript version, external resource availability and the embedded Ruffle runtime. SWF One is not affiliated with Adobe or with the creators of user-selected content.
