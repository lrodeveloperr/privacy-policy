# SWF One Privacy Policy

**Effective and last updated:** 19 November 2026  
**Publisher:** WorksBien Studios Inc., Ontario, Canada  
**Contact:** [lrodeveloperr@gmail.com](mailto:lrodeveloperr@gmail.com)

This policy applies to the Android app SWF One, package `com.worksbien.swfone`.

## Summary

SWF One has no developer account, advertising, behavioural analytics, tracking SDK or developer-operated backend. WorksBien Studios Inc. does not receive the SWF files, control layouts, recent sources or Flash save data used in the app.

The app has internet access because a user can open a web address and because SWF content can request external resources. A remote site selected by the user can receive ordinary network information such as the device IP address, request time and user agent under that site's own policy.

## Data handled on the device

SWF One can handle:

- SWF files selected with Android's system file picker;
- SWF files and pages downloaded from addresses entered by the user;
- virtual-control layouts and app preferences;
- the most recent source needed for the subscriber resume feature;
- local storage created by compatible SWF content inside the embedded player; and
- Google Play subscription entitlement returned by the Play Billing service.

Downloaded or imported SWF content is copied to the app cache for playback. The current cached copy is replaced when new content is opened, and Android can remove cached data. Local settings remain until the user clears app storage or uninstalls the app. A file selected through Android can remain available through Android's persisted file-access permission.

SWF One does not upload this local content to WorksBien Studios Inc.

## Optional cloud sync

Cloud sync is off by default and is available to subscribers. When a user turns it on, SWF One asks Android's backup service to back up supported play-setup data associated with the user's device account. The backup contains virtual-control layouts and, when the recent source is a web address, that last web address. It does not contain SWF files, local document addresses, Flash save data, advertising identifiers or analytics data.

Android and the selected backup transport, commonly Google's Android backup service, process this backup under their own terms and privacy policies. WorksBien Studios Inc. does not operate or receive the backup. Turning cloud sync off requests deletion of the app's cloud-backup entity; transport processing and retention timing are controlled by Android and the backup provider.

## Google Play purchases

The app uses Google Play Billing for monthly and annual subscriptions. Google Play processes payment details. The app reads purchase and entitlement status so it can unlock paid features and acknowledge a completed purchase. SWF One has no developer server and does not send purchase tokens or payment information to WorksBien Studios Inc.

## Network requests and third-party content

When a user opens a URL, SWF One connects directly to that address and can inspect the returned page to locate an SWF reference. The embedded Ruffle player can also make network requests requested by the SWF. Those third-party hosts may collect network data or set their own content rules. Users should open only content and sites they trust and are authorized to use.

## Permissions

SWF One requests the Android `INTERNET` permission. Local files are selected through Android's system file picker; the app does not request broad storage access, contacts, location, camera, microphone or advertising permissions.

## Sharing, sale and retention

WorksBien Studios Inc. does not sell or share personal data from SWF One because it does not receive app-use data. Device data remains subject to user actions, Android storage management and any optional Android backup described above.

## Removal and choices

Users can:

- turn cloud sync off in SWF One;
- clear SWF One storage in Android settings;
- revoke file access or remove the original file;
- manage or cancel the subscription in Google Play; and
- uninstall the app.

See [Support and Data Removal](../support/) for steps.

## Children

SWF One is a general-purpose player and is not directed to children under 13. It does not provide a curated game catalogue or social features. Parents and guardians control which third-party files and sites a child can open.

## Security and changes

SWF One limits storage and access to what is needed for playback and the selected features. No method of device storage or internet transmission is completely secure. Material changes to this policy will be posted on this page with a new effective date.

Questions can be sent to [lrodeveloperr@gmail.com](mailto:lrodeveloperr@gmail.com). Do not send SWF files, passwords, payment-card details or other sensitive content.
