# LED Light Remote — Support and Saved-Light Data Removal

## Fast troubleshooting

1. Confirm the light and Bluetooth controller have power.
2. Close the manufacturer's or another controller app; many low-cost controllers accept only one connection.
3. Move within 3 metres, power-cycle the controller and scan again.
4. Select the exact nearby device and use the free red/green/blue response test.
5. If colours are swapped, use colour-channel calibration before deciding whether the light works.

The demo is simulated. It is useful for previewing the interface, but it does not transmit commands or establish compatibility.

## Remove saved-light data

- Remove one saved profile by swiping it in **Settings → Saved lights**.
- Remove all saved profiles with **Settings → Delete all saved-light data**.

This removes saved peripheral identifiers, names, rooms, detected protocol families, colour mappings, last colours, brightness and compatibility flags. It does not delete Apple's purchase history or the App's separate local trial-integrity clock value. Uninstalling removes ordinary local preferences subject to iOS and backup behaviour. Because the App has no WorksBien account or cloud database, WorksBien Studios cannot remotely erase data it never receives.
