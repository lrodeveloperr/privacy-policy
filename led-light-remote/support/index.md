# Support and Data Removal for LED Light Controller Remote

**Applies to:** LED Light Controller Remote 1.0 for iPhone and iPad

## Fast troubleshooting

1. Confirm the light and Bluetooth controller have power.
2. Close the manufacturer's app and any other controller app; many low-cost controllers accept only one connection.
3. Move closer to the controller, power-cycle it and scan again.
4. Select the exact nearby device and confirm that the App marks its protocol as supported.
5. Test power, colour and brightness on the physical light before subscribing.

Demo Mode is simulated. It previews the interface but does not send commands or establish compatibility.

## Remove local App data

Use **Settings → Remove all saved data** to delete saved lights, groups and custom scenes stored by the App. This action does not cancel LED Controller Pro, delete Apple's purchase history or remove an existing iCloud or Finder device backup. WorksBien Studios cannot remotely erase App records it never receives.

To remove data held in a device backup, use Apple's iCloud or Finder backup controls. Restoring an older device backup may restore App data that existed when that backup was created.

## Restore or cancel LED Controller Pro

Use **Settings → Restore subscription** to recover an eligible active subscription for the same Apple Account. Manage or cancel the subscription in App Store subscription settings. Deleting the App does not cancel a subscription.

If Pro has expired, select one saved light under **Lights → Free access** to continue controlling it. Other saved lights, groups and custom scenes remain visible and are not deleted; restoring or renewing Pro unlocks them again.
