# Support for Deposit Exception Checker

**Email:** [info@worksbienstudios.com](mailto:info@worksbienstudios.com)  
**Provider:** WorksBien Studios Inc., 350 Bay Street, Suite 1300B, Toronto, Ontario M5H 2S6, Canada

When requesting support, include the date, browser, a short description of the step that failed, and the stable error code shown by the Service. If relevant, include the workspace name and run ID.

Do not send Intuit passwords, OAuth codes or tokens, payment-card details, full QuickBooks exports, raw API responses, or screenshots containing unnecessary customer or accounting information. We will never ask for your Intuit password.

## Common actions

- **Authorization expired:** reconnect the company from the Companies page.
- **Wrong company connected:** disconnect it, then connect the correct QuickBooks company.
- **A finding looks wrong:** compare the listed source record IDs and amounts directly in QuickBooks. Reply with the rule ID and run ID, not a full accounting export.
- **Need to remove data:** follow the [account and data deletion instructions]({{ '/quickbooks-deposit-exception-checker/deletion/' | relative_url }}).

The Service cannot edit or correct QuickBooks records. Make corrections directly in QuickBooks through an authorized accounting professional.
