# 完全論理事件簿 サポート

## よくある質問

### 購入済みの事件を復元したい

アプリ内の購入復元機能を使用してください。同じApple Accountで購入した場合に限り、AppleのApp Storeを通じて復元されます。

### 購入したのに解放されない

アプリを再起動し、購入復元をお試しください。改善しない場合は、下記の情報を添えてサポートへご連絡ください。

- ご利用の端末機種
- iOSまたはiPadOSのバージョン
- アプリのバージョン
- 問題が起きた手順
- 表示されたエラーメッセージ（ある場合）

支払いカード情報、Apple Accountのパスワード、またはその他の機密情報は送信しないでください。
